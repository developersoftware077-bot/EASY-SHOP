# EASY SHOP

EASY SHOP is a bilingual English/Swahili storefront built with TanStack Start, React, Tailwind CSS, and Supabase. Customers can browse product and category pages, save a stock-limited cart locally, and submit orders to WhatsApp. Supabase calculates prices and reserves stock when an order is created. The responsive `/admin` area supports products, categories, orders, and store settings.

See [SETUP.md](SETUP.md) for local setup, database security, and deployment.
